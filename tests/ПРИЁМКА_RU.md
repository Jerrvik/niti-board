# Критерии приёмки первой тестовой версии

**Условия готовности:** выполненные пункты с доказательствами и отдельный список невыполненных. Значение «тесты прошли» должно обозначать реальные запуски, а не предположения по коду.

| ID | Критерий | Доказательство / тест |
|---|---|---|
| AC-01 | Foundry V14 распознаёт модуль и включает его | Скриншот тестового мира/лог запуска |
| AC-02 | Окно доски открывается, перемещается, изменяет размер | Видео/ручной тест |
| AC-03 | Из Actor Directory перетаскивается NPC с именем и фото | Ручной Foundry тест GM |
| AC-04 | Игрок не может импортировать скрытого Actor | Тест ролей/прав |
| AC-05 | Ручная карточка переключает фото/компактный вид | UI тест |
| AC-06 | Игрок создаёт линию, меняет подпись/цвет/стрелку/пунктир | UI тест игрока |
| AC-07 | Игрок может исправить и удалить свою связь без GM | Тест нескольких клиентов |
| AC-08 | Связь следует за карточкой при перетаскивании | UI тест |
| AC-09 | Две разные связи между одними NPC доступны отдельно | UI тест |
| AC-10 | Стикер редактируется и перемещается | UI тест |
| AC-11 | Область меняет положение/размер/название | UI тест |
| AC-12 | Игрок не может случайно удалить защищённый NPC, но может создать связь к нему | Проверка авторизованной операции |
| AC-13 | Изменения игрока A отображаются у GM и игрока B | 3 независимых клиента |
| AC-14 | Одновременные независимые операции обоих игроков сохраняются | Конкурентный тест |
| AC-15 | Подтверждённая правка не исчезает из-за запоздалого пакета | Модель/интеграция + тест |
| AC-16 | GM офлайн: редактирование блокируется, статус честен | Тест отключения |
| AC-17 | Перезагрузка 3 клиентов не теряет доску | Тест реальной Foundry |
| AC-18 | При отказе сохранения пользователю показывается ошибка/возможность пересинхронизации | Искусственный сбой или интеграционный тест |
| AC-19 | Экспорт JSON → импорт → эквивалентная схема | Unit/UI тест |
| AC-20 | XSS через заметки, подписи, фото URL не выполняется | Негативные тесты |
| AC-21 | Файл ZIP содержит `niti-board/module.json` и ссылки на существующие файлы | Скрипт проверки архива |
| AC-22 | Manifest URL и release ZIP открываются публично без входа | HTTP проверки после публикации |
| AC-23 | GitHub не содержит секретов, рабочих миров и чужих портретов | Review содержимого перед публикацией |
| AC-24 | Проверены V14.361 и V14.364 либо явно указан неиспытанный билд | Матрица тестов |

**Нельзя скрывать провал P0:** если AC-03, AC-06, AC-13, AC-17, AC-20 не выполняются, BETA не готова к передаче мастеру как рабочая. Можно передать только как демонстрацию с известным дефектом и явным предупреждением.

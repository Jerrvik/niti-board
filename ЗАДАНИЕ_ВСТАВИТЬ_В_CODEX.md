# Сообщение для Codex

Продолжаем разработку отдельного модуля **«Нити» (niti-board)** для **Foundry VTT V14**.

Открой всю папку проекта, прочитай `AGENTS.md`, `CODEX_START_RU.md`, `docs/ТЗ_RU.md`, `docs/UX_RU.md`, `docs/АРХИТЕКТУРА_И_РИСКИ_RU.md`, `tests/ПРИЁМКА_RU.md` и `docs/GITHUB_RELEASE_RU.md`.

В `src/niti-board/` лежит **исходный код первой BETA**, а не финальная версия. Используй его как основу, исправь недостатки и доведи до удобного полноценного модуля. Приоритет — перетаскивание NPC из Actor Directory, самостоятельное создание/редактирование связей **игроками**, одна общая синхронизированная доска, сохранение после перезагрузки. Стикеры и области должны быть простыми второстепенными инструментами. Сохрани тёмную минималистичную визуальную концепцию.

Особенно проверь безопасность и проверку прав, работу в нескольких клиентах, авторитетную запись изменений, ACK/revision/resync, конкуренцию правок, ошибочное удаление защищённых NPC и приватность скрытых Actor. Не заявляй, что мультклиентный тест прошёл, если его не проводил.

Запусти `npm run check`, `npm test`, затем расширь тесты и собери ZIP (`python tools/build_zip.py`) с `niti-board/module.json` в архиве. По возможности проверь Foundry **14.361 и 14.364**; неизвестную совместимость честно обозначь как непроверенную.

После тестов **проверь `gh auth status`, подготовь отдельный публичный репозиторий GitHub и новый BETA Release**, настрой `module.json` с постоянным Manifest URL и ссылкой на версионный ZIP. Не трогай репозиторий Right to Speak. Если нужна моя авторизация/подтверждение публикации — спроси об этом отдельно, не требуй токен в чат.

Результат: исходники, установочный ZIP, README мастера, отчёт о проверках и **проверенные публичные ссылки** на репозиторий, Manifest URL, Release и ZIP. Не заканчивай работу на планировании или отчёте без сборки, если нет реального блокера.

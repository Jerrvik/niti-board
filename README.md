# Нити — доски связей для Foundry VTT

**BETA 0.3.0-beta.2.** Общие и личные доски с карточками Actor, связями, стикерами и областями. Исходная общая доска сохраняется при обновлении.

## Установка

- [Manifest для Foundry V14](https://raw.githubusercontent.com/Jerrvik/niti-board/main/src/niti-board/module.json) — проверено на V14.364.
- [Тестовый manifest для Foundry V13](https://raw.githubusercontent.com/Jerrvik/niti-board/main/manifests/v13-test.json) — работа в V13 ещё не подтверждена реальным испытанием.
- [Релиз и ZIP-архивы](https://github.com/Jerrvik/niti-board/releases/tag/v0.3.0-beta.2).

В Foundry Setup откройте **Add-on Modules → Install Module**, вставьте подходящий Manifest URL и включите модуль в мире. Перед обновлением сделайте резервную копию мира.

## Использование

- В списке слева переключайте доски, создавайте общие и личные, переименовывайте и удаляйте их. Личная доска доступна владельцу и GM.
- Перетаскивайте Actor из каталога или компендиума. Имя и портрет берутся из Actor; портрет карточки можно заменить вручную.
- Выберите **Соединить** и два объекта. Карточки и стикеры можно привязывать к областям; при переносе области содержимое движется вместе с ней.
- Перемещайте плоскость мышью, меняйте масштаб колесом или кнопками и используйте **Показать всё**. Камера сохраняется для пользователя.
- GM выбирает общую готическую или фэнтезийную тему в настройках модуля.

Для записи нужен подключённый GM. Перед созданием личных досок GM нажимает **«Открыть личные доски (GM)»** в панели «Нити» и задаёт пароль длиной не менее 16 символов; после нового подключения вводит его там же. **Сохраните пароль:** без него личные доски не восстановить. Их содержимое хранится в настройке мира в зашифрованном виде; доступ к расшифрованным данным выдаёт GM владельцу доски. Используйте длинный непредсказуемый пароль. Общие доски видны всем участникам мира.

Если два участника одновременно меняют один объект, конфликтующая правка отклоняется с сообщением и обновлением доски. Для сообщения об ошибке укажите версию Foundry, браузер, действия и текст ошибки. Результаты проверки V13 мастером нужны для подтверждения её совместимости.

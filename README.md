# Нити — общая доска связей для Foundry VTT 14

**Версия:** `0.1.0-beta.2`. Одна публичная доска мира: карточки NPC, редактируемые игроками связи, стикеры и области. Игровая система не влияет на формат данных. Для записи игроками нужен подключённый GM.

## Установка

1. Сделайте резервную копию мира. Эта BETA испытана в тестовом мире Foundry **14.364**; билд 14.361 пока не проверен.
2. В Foundry Setup откройте **Add-on Modules → Install Module** и вставьте Manifest URL:

   `https://raw.githubusercontent.com/Jerrvik/niti-board/main/src/niti-board/module.json`

3. В тестовом мире включите **«Нити — Доска связей (BETA)»** в управлении модулями. После перезагрузки нажмите **«⌁ Нити · доска»** слева внизу.
4. Для ручной установки распакуйте `niti-board.zip` в `{UserData}/Data/modules/`. Должен получиться путь `{UserData}/Data/modules/niti-board/module.json`.

## Как пользоваться

- Откройте вкладку **Актёры** справа и перетащите Actor на доску. Имя и изображение берутся из документа. Игрок может добавить только доступного ему Actor. Перед публикацией скрытого Actor GM увидит предупреждение.
- Выберите **«Соединить»**, затем нажмите первую и вторую карточку. В свойствах справа меняйте подпись, цвет, пунктир и стрелку. **«Развернуть стрелку»** меняет направление без пересоздания связи.
- Карточки можно двигать; линии следуют за ними. Две связи между одной парой разводятся. GM может защитить карточку от удаления игроками, не запрещая связи к ней.
- **Экспорт JSON** создаёт резервную копию. При импорте показываются размеры схемы и автоматически скачивается копия текущей доски перед заменой.
- Статус **«Сохранено»** появляется после записи GM. При отсутствии GM доска переходит в просмотр.

## Ограничения BETA

- Вся доска публична для участников мира; секретных слоёв нет. Публикация скрытого Actor раскрывает его имя, портрет и UUID на доске.
- При одновременной правке одного объекта вторая операция отклоняется с сообщением; её нужно повторить на обновлённой доске. Независимые операции сохраняются. Undo работает для собственных последних подтверждённых операций, пока не пришла чужая правка.
- До 400 объектов, 900 связей и 750 КБ JSON. Портреты в data URL ограничены 100 КБ; локальные пути к файлам Foundry предпочтительнее.
- Проверены Foundry 14.364, один GM и два игрока в тестовом мире. **14.361 и установка через Manifest в UI Foundry пока не проверены.** Английской локализации нет.
- Модуль не предоставляет серверную защиту от пользователя, который меняет код своего клиента или имеет доступ к GM-сессии. Правила подтверждаются активным GM-клиентом через `User.query`.

## Разработка и проверки

Исходник модуля: `src/niti-board/`. Проверки: `npm test`, `npm run check`, `npm run package`. Для ZIP нужны только Node.js и его встроенные модули; большие зависимости не используются. ZIP содержит одну корневую папку `niti-board/`.

Отчёт проверок: [docs/ПРОВЕРКИ_BETA2_RU.md](docs/ПРОВЕРКИ_BETA2_RU.md). Ручной сценарий: [tests/РУЧНЫЕ_ТЕСТЫ_RU.md](tests/РУЧНЫЕ_ТЕСТЫ_RU.md).

## Обратная связь

Сообщите билд Foundry, игровую систему, браузер, действия до ошибки и текст ошибки. Особенно полезно: насколько быстро игрок создаёт, выбирает и исправляет **несколько связей между NPC**.

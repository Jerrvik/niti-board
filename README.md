# Нити — общая доска связей для Foundry VTT

Одна доска мира для NPC, связей, стикеров и областей. Игроки могут создавать и редактировать связи; изменения сохраняет подключённый GM. Вся доска видна участникам мира.

**Текущая версия:** `0.2.0-beta.1`.

## Установка

- **Foundry V14 (проверено на 14.364):** [Manifest URL](https://raw.githubusercontent.com/Jerrvik/niti-board/main/src/niti-board/module.json)
- **Foundry V13 (тестовая сборка, совместимость пока не подтверждена):** [Manifest URL для V13](https://raw.githubusercontent.com/Jerrvik/niti-board/main/manifests/v13-test.json)

В Foundry Setup откройте **Add-on Modules → Install Module**, вставьте подходящий Manifest URL и включите «Нити» в мире. [Релиз и архивы](https://github.com/Jerrvik/niti-board/releases/tag/v0.2.0-beta.1) доступны для ручной установки.

## Использование

- Перетащите Actor из каталога или компендиума на доску. Имя и портрет берутся из Actor; портрет можно заменить вручную. Если изображение отсутствует, показывается заглушка.
- Выберите **Соединить**, затем два объекта. Подпись, цвет и направление связи меняются справа.
- Карточки и стикеры можно привязать к области. При переносе области они движутся вместе с ней; маркеры меняют её размер. Цвет области настраивается в свойствах.
- GM выбирает общую готическую или фэнтезийную тему в настройках модуля. Свёрнутый значок каждый участник может передвинуть для себя.
- Перед обновлением мира сохраните резервную копию. **Экспорт JSON** сохраняет доску отдельно.

При одновременной правке одного объекта вторая операция отклоняется с сообщением и обновлением доски. Для работы игроков с записью нужен подключённый GM. Секретных слоёв в этой BETA нет.

Для обратной связи укажите версию Foundry, браузер, действия и текст ошибки. Результаты проверки V13 другим мастером особенно важны перед подтверждением её совместимости.

# Инструкция для передачи мастеру после релиза Codex

Пример сообщения мастеру:

> Я сделал тестовую BETA «Нитей» — общей доски NPC и связей для Foundry V14. Главная идея: GM просто перетаскивает актёров на доску, а игроки сами строят и исправляют связи между ними. Есть стикеры, области и два вида карточек. Это отдельный модуль, не меняет существующую доску.
>
> Ссылка для установки: **https://raw.githubusercontent.com/Jerrvik/niti-board/main/src/niti-board/module.json**.
>
> Пожалуйста, сначала проверь в тестовом мире с резервной копией. Особенно интересно, удобно ли игрокам соединять карточки и править линии, не отвлекая мастера. Если не заработает — пришли номер билда Foundry, скриншот и ошибку из Console.

Минимальная проверка: установка → два NPC → связь → изменение игроком → перезагрузка → восстановление.

Сценарии в GM + двух игроках проверены в Foundry 14.364; статус всё ещё **BETA**. Доска целиком публична для игроков мира. Скрытые NPC нельзя публиковать без сознательного действия GM.

# Проверки «Нити» 0.1.0-beta.2

## Автоматические

- `npm test`: 13 модельных тестов, включая независимые и конфликтующие правки, защиту карточки, удаление при новой связи, JSON, URL и подтверждение операции отправителем.
- `npm run check`: синтаксис JS, встроенного скрипта HTML и JSON манифеста/локализации.
- `npm run package`: проверка ZIP, корневого пути `niti-board/module.json` и файлов манифеста.

## Реальная Foundry

Локальная установленная **Foundry 14.364**, Universal Tabletop System 1.2.1, тестовый мир `testovyj-mirok`, три отдельные вкладки с подключёнными сессиями **Gamemaster, Игрок A Нити, Игрок B Нити**. В тестовом мире также был активен существующий Right to Speak; его файлы и настройки не менялись.

- Модуль обнаружен в управлении модулями, включён, после перезагрузки появилась кнопка и открылось окно. Foundry отдаёт `.html` как `text/plain`; первоначальная попытка загрузить iframe через `src` дала пустую доску. Исправлено загрузкой HTML через `fetch` и `srcdoc`, повторно проверено.
- GM создал две карточки, связь, подпись и стрелку; изменения получили номера ревизий 1–6 и сохранились после перезагрузки страницы.
- GM перетащил тестового Actor из Actor Directory в отдельное окно: карточка получила его имя и локальный портрет, сохранение подтверждено ревизией 7.
- Игрок A создал связь (ревизия 8). Она появилась у игрока B и GM без перезагрузки. Игрок B изменил подпись (ревизия 10), она появилась у игрока A.
- GM защитил карточку (ревизия 9); игрок A получил предупреждение при попытке удаления. Связь к ней была создана игроком.
- A и B почти одновременно добавили по стикеру. Оба объекта присутствовали на доске с ревизией 12.
- GM перетащил Actor, скрытого от обоих игроков. Появилось предупреждение «не виден 2 игрокам»; публикация отменена. В Actor Directory игрока этот Actor отсутствовал.
- После отключения GM и повторного входа игрока доска показывала «Нет GM · только просмотр». Для живого переключения статуса заменён обработчик на документированный V14 hook `userConnected`; повторный сценарий отключения после этой правки ещё не выполнен.
- После усиления проверки отправителя GM повторно создал стикер; запись прошла как ревизия 13 и появилась у игрока после перезагрузки. Новый запрет публикации Actor, скрытого хотя бы от одного игрока, проверен чтением кода и статической проверкой, но не отдельным трёхклиентным сценарием.

## Не проверено и ограничения

- Foundry **14.361** отсутствует локально. Совместимость с этим билдом не заявлена как испытанная.
- Установка именно через Manifest URL в UI Foundry и механизм обновления проверяются после публикации ссылок; если в итоговом отчёте это не подтверждено отдельно, считать непроверенным.
- Долгий сетевой обрыв, смена активного GM между двумя GM-сессиями, искусственный отказ записи и злонамеренно модифицированный клиент не испытывались в реальной Foundry.
- Закрытие повторно открытой вкладки GM не сняло его из списка подключённых Foundry в течение короткого наблюдения; живое переключение режима в этом прогоне не подтверждено. После перезагрузки игрока без GM режим просмотра подтверждён.
- Модельные тесты покрывают пересечение операций, но не являются полной серверной проверкой авторизации Foundry.

# Нити 0.1.0-beta.2

Модуль Foundry VTT 14 с одной общей публичной доской связей. Установка через Manifest URL и проверенные сценарии описаны в корневом README репозитория.

Содержимое папки `niti-board/` устанавливается целиком в `{UserData}/Data/modules/`. Для записи игроков нужен подключённый GM; без него доска доступна только для просмотра.
